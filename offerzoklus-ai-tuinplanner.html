Voor hoveniers: zet deze tool op je eigen website

Geef een hovenier een eigen link of plaats de tool met een iframe op zijn website. De bezoeker ziet de naam van de hovenier en de aanvraag komt direct bij die hovenier binnen.

Voorbeeld eigen link voor een hovenier:

https://offerzoklus.nl/ai-tuinplanner?partner=demo-hovenier

Voorbeeld code om op de website van de hovenier te plaatsen:

In deze demo werkt een hovenier-versie via ?partner=demo-hovenier. Later kun je per hovenier een eigen link maken, bijvoorbeeld ?partner=jansen-hoveniers.
